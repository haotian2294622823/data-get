# V0.3 重建 Implementation Plan

> For agentic workers: 使用 Superpowers 测试驱动开发和完成验证流程逐项执行。

**Goal:** 从单 LOT 追溯真实形状的材料事实，保留事件和路径，独立导出工序及明细。
**Architecture:** Python 业务服务与 Streamlit UI、数据访问隔离。Mock 工厂每操作冻结 CSV；真实 PostgreSQL 工厂使用同一只读一致性事务。
**Tech Stack:** Python、Streamlit、pandas、SQLAlchemy、PyYAML、pytest、AppTest。
**Spec:** 根目录《制造批次追溯与自助数据抽取系统_开发文档_V0.3.md》，由用户指定为实施依据。

## Global constraints
- 不补造工序，不称未匹配批号为外部原料，不开放未核实真实字段或 root_summary。
- 事件、路径、工序、原始材料独立粒度；预算跨层累计，超限无 CSV。
- 密码登录；trace_form、extract_form 两次提交；正式生成时刷新全部事实。

## Review focus
- 空批号、空工序引用及图外工序引用：材料始终保留。
- 共享祖先和重复投入：事实唯一、不同前缀路径分别保留。
- 深度恰为叶节点与预算恰好耗尽：不误报截断。
- 新提交失败或模式/配置变化：不能泄漏旧 CSV。
- 真实源未配置、读取失败和不存在 LOT：明确不同错误。
