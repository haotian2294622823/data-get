## M1—M4

- 类型与数据源协议独立于 Streamlit；模拟数据每次会话深拷贝冻结。
- 按层 BFS，读取缓存/节点/材料事件/路径前缀分开；规范 JSON 编码业务键，保留原始编号。
- 材料按内部 LOT 读取，包括空批号、缺工序与图外冲突引用；图外工序只核验不扩图。
- 工序按主表事实输出；设备和不良为模拟明细独立文件，没有跨表笛卡尔积。
- 两次提交各开新快照；新图/数据集/列映射/CSV 一次性发布。失败清旧 CSV，草稿与已提交结果分开。
- 密码恒时比较、会话级短暂锁定、退出清理、版本/模式失效与空数据集状态。
- 正式导出使用完整结果。页面静态表无隐式预览 CSV 工具栏，避免绕过生成或不完整结果禁下载规则。

## 验证与审查

- 最终验收：39 项 pytest 全部通过；mypy 检查 20 个应用源文件无错误；Ruff 格式与未使用导入检查通过。
- pytest 覆盖基准 5/6/8/5/6 数量、全部文档材料变体、循环、边界深度、累计限额、稳定 ID、缺失源、空结果、字段与请求版本、CSV 全量/编码/公式/文件上限。
- AppTest 覆盖认证、退出、新会话隔离、双提交、新 LOT 清结果、生成失败清旧 CSV、仅切换预览不取数、锁定期结束后直接重试。
- 独立审查发现末尾核验超时漏检及登录按钮锁定不能直接重试；先添加失败回归测试，再修复。告警去重改为集合，关键循环与最终整理均检查截止时间。
- mypy 检查应用和 src，禁止将“语法能编译”当作运行验收。
- 启动 Streamlit 实例，用浏览器实际验证登录、ROOT_A 追溯及生成；读到 5 节点/6 事件/8 路径/5 工序，以及四个基础数据集的下载入口。控制台无新增异常。
- 官方 Skill 来自 develop 分支，其中 agent API 验证选项在本机固定 Streamlit 1.66.1 中尚不可用（No such option）。本次采用 AppTest 与实际浏览器验证，不宣称执行了 agent API。
